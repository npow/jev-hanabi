# discard threshold pilot

This 10-game pilot raised the discard safety threshold from 0.10 to 0.20,
while retaining the one-action clue criterion and all other current
best-policy settings.

- Mean: **14.0/25**
- Scores: 16, 13, 14, 13, 15, 17, 13, 13, 14, 12
- All 10 games retained all 3 lives
- Seeds: 0–9
- Mean actions: 14.0 plays, 33.8 clues, 27.1 discards

This is a promising pilot but not a promotion. The 50-game replication is
defined by `run_discard_threshold_20_replication.sh`.

# risk-sensitive score pilot

This pilot uses the one-action clue criterion plus a 0.5 penalty on
JEV's probability of assigning the harmful rating.

- Seeds 0–9, 10 games, 2-player self-play
- Mean score: **13.9/25**, median 14, range 12–17
- All 10 games retained all 3 lives

The pilot is not expanded: it is only +0.2 over the old threshold-0 pilot
(13.7/25), and the complete baseline is 14.61/25 on seeds 10–109.

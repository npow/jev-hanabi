# Matched risk-penalty control

This 50-game control uses the same seeds (50–99) and policy as the
risk-penalty 0.1 replication, with `HANABI_SCORE_RISK_PENALTY=0`.

- Mean: **14.52/25**
- 95% normal interval: **13.92–15.12**
- Games: 50/50 complete
- All games retained all 3 lives

The 0.1 penalty candidate minus this control was +0.12 (95% CI −0.42 to
+0.66), so the penalty was not promoted.

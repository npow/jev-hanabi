# Exploratory signal-gate run (incomplete)

This directory contains 45 completed games from the planned 100-seed Sherlock run. The run was stopped after inspection found that the prompt did not make the intended action priority explicit: JEV sometimes gave another clue even when a guaranteed-safe play was available. The raw trajectories are preserved for diagnosis; do not use this run as the final score estimate. `partial_manifest.json` records the completed seeds and raw-data hash. The corrected prompt is evaluated separately in `results_hle_signal_priority_100/`.
